# ББ / ДВ

Нативное приложение для macOS: голосовое управление ботами Telegram, рандомайзер с ручной отправкой и локальный анализ лица по собственным эталонам.

**Версия 1.3.1 · Apple Silicon · macOS 15.2+ · SwiftUI / AppKit**

| Режим | Что делает |
| --- | --- |
| Голос · Бибинта | Находит число от 1 до 10 внутри фразы, вставляет его и отправляет через Enter |
| Голос · Давинчик | Находит команды лайка и дизлайка внутри фразы и отправляет настроенный эмодзи |
| Рандомайзер | После появления новой анкеты подставляет случайный ответ; Enter нажимает пользователь |
| Оценка лица · отладка | Сравнивает лицо с локальными эталонами и показывает ближайшие категории и карту лица |

Анализ выбранной области экрана работает поверх **любого приложения**. Управление ботами рассчитано на Telegram для Mac. Приложение не связано с Telegram или разработчиками ботов.

## Сборка и запуск

Понадобятся Mac с Apple Silicon, macOS 15.2 или новее, Command Line Tools и **Python 3.12**. Python нужен только для сборки локального детектора: в готовое приложение он упаковывается вместе с зависимостями.

```sh
git clone https://github.com/segeitsi/bb-dv.git
cd bb-dv
xcode-select --install  # если Command Line Tools ещё не установлены
bash scripts/build.sh
open "build/ББ ДВ.app"
```

Если Python 3.12 не находится командой `python3.12`, укажи его явно:

```sh
BBDV_BUILD_PYTHON=/path/to/python3.12 bash scripts/build.sh
```

Также можно запустить `Запустить.command`: при отсутствии готового приложения он сначала выполнит сборку.

Первая сборка требует интернета: зависимости устанавливаются в отдельное окружение `build/mesh-venv`, модель MediaPipe скачивается с официального сервера Google и проверяется по закреплённой SHA-256. Модель и результаты сборки не входят в Git. Во время анализа фотографии не загружаются в сеть.

## Разрешения macOS

Разрешения выдаются для конкретной локальной сборки **ББ ДВ** в «Системные настройки → Конфиденциальность и безопасность».

| Разрешение | Для чего нужно |
| --- | --- |
| Универсальный доступ | Вставка ответов и нажатие Enter в Telegram, глобальная клавиша остановки |
| Микрофон и распознавание речи | Голосовой режим |
| Запись экрана | Наблюдение за выбранным фрагментом экрана и рандомайзер |

Для анализа файла через «Открыть фото» доступ к экрану не нужен. Сам режим анализа лица ничего не вводит и не отправляет в другие приложения.

Сборка подписывается локальной ad-hoc подписью. После пересборки macOS может потребовать обновить разрешение. Сначала перезапусти приложение; если включённый тумблер не помогает, удали только запись ББ ДВ из соответствующего списка, добавь текущий `build/ББ ДВ.app` и включи доступ заново.

## Анализ области любого приложения

1. Запусти приложение. В строке меню macOS появится значок видоискателя.
2. Открой фото в браузере, «Просмотре» или другой программе.
3. Нажми значок ББ / ДВ → **«Выбрать область и наблюдать»** и обведи фото. Наблюдение начнётся после выделения; главное окно открывать не нужно.
4. Для просмотра результата выбери **«Показать окно»**. Окна ББ / ДВ исключены из захвата.
5. **«Остановить всё»** приостанавливает обработку; **«Продолжить наблюдение»** использует ту же область.

Источник — изображение рабочего стола. На анализ передаётся только выбранный прямоугольник. Смена активного приложения не останавливает наблюдение. Если фрагмент перекроет другая программа, анализируется её содержимое; окна самой ББ / ДВ исключены.

Область закреплена в координатах одного монитора и не следует за фото. После перемещения или изменения масштаба фото, смены разрешения или отключения монитора выдели её заново. Минимальный размер области — 80 × 80 точек.

Кнопка **«Выделить фото на экране»** в основном окне даёт три секунды на переключение и также запускает наблюдение после выделения. Разбор обновляется после двух стабильных кадров. Закрытие главного окна оставляет приложение в строке меню; для полного выхода используй **«Завершить ББ / ДВ»** или Cmd+Q.

## Категории по собственным эталонам

В публичном репозитории **нет личных эталонов, фотографий, миниатюр или готовой пользовательской базы**. После сборки из чистых исходников базы фотографий и рисунков пустые.

1. Во вкладке **«Оценка лица · отладка»** нажми **«Открыть фото»**. Если лиц несколько, выбери нужное.
2. Выбери тип изображения: **«Фотографии»** или **«Рисунки»**. Базы раздельные.
3. Укажи свою категорию в **«Моя категория»** и нажми **«Добавить эталон»**. Сохраняются миниатюра выбранного лица и его признаки.
4. Добавь примеры разных лиц и ракурсов. Для сравнения достаточно двух разных категорий; заполнять все семь необязательно.
5. Открой другое фото или включи наблюдение за областью экрана. Приложение покажет ближайшие примеры и результат сравнения.

Поддерживаемые метки: **sub 3 → sub 5 → LTB → MTB → HTB → stacy → true eve**. Отсутствие отдельных меток не блокирует результат: например, HTB может выбираться и без эталонов true eve.

При достаточно близком и однозначном совпадении показана выбранная категория. При слабом сходстве, единственной категории или небольшом отрыве между вариантами показана **«Ближайшая категория»** с пояснением. Расстояния до эталонов означают визуальное сходство, а не балл привлекательности или вероятность.

**Ограничения.** Это экспериментальное сравнение изображений через Apple Vision Feature Print revision 2, а не обученная и проверенная модель привлекательности. На сходство влияют причёска, освещение, ракурс, фон и стиль изображения. Для выбора категории используются расстояние не больше половины межклассового расстояния ближайшего эталона и отрыв от следующей категории. Пороги не откалиброваны на независимой выборке. Геометрические измерения в раскрываемом разделе не определяют категорию.

### Карта лица

Локальный [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker) строит сетку из 478 точек с контурами глаз, бровей, губ и овала. При пропуске лица проверяются повороты ±30°, ±60° и ±90°; точки переводятся обратно в исходное изображение. Если подробная сетка недоступна, приблизительные точки Apple Vision показаны оранжевым с соответствующей подписью.

Переключатель **«Показать карту лица»** помогает сравнить её с оригиналом. Профиль, очки, волосы, пересвет и закрытые черты могут ухудшать обнаружение и положение точек.

## Голосовое управление Telegram

1. Во вкладке **«Управление ботами»** выбери бота и режим **«Голос»**.
2. Открой нужного бота в Telegram. Нажми **«Указать поле ввода»** и за четыре секунды вернись к чату. Кликни в пустое поле сообщения, а не в кнопку бота. Esc отменяет выбор.
3. Нажми **«Запустить»** и открой Telegram. Ввод выполняется только в настроенном окне Telegram на переднем плане.

Бибинта распознаёт число в любой части предложения: «ну этой пять, идём дальше». Через 0,35 секунды после распознавания числа ответ вставляется и отправляется. Если за это время сказать «пять, нет, семь», выбирается последнее число. Следующую команду можно произносить без перезапуска режима.

В Давинчике работают фразы вроде «ну эту дизлайк», «ставь ей лайк». Дизлайк имеет приоритет над лайком. Эмодзи по умолчанию — `❤️` и `👎`; их можно изменить под кнопки своего бота. В Telegram должен быть включён режим **«Enter отправляет сообщение»**.

Речь распознаётся на устройстве, если локальное распознавание доступно. Иначе используется сервис распознавания Apple. Возможны ошибки распознавания; голосовой режим отправляет ответ автоматически.

## Рандомайзер

1. Выбери бота и режим **«Рандомайзер»**.
2. Настрой поле сообщения и выдели область одной анкеты внутри того же окна Telegram, исключив кнопки, поле ввода и предыдущие анкеты.
3. Для Бибинты задай диапазон 1–10, для Давинчика — вероятность лайка.
4. Запусти режим и вернись к нужному чату. После стабильного кадра появится черновик.
5. Проверь его и **сам нажми обычный Enter**. Следующий черновик появится после Enter и изменения анкеты.

**Рандомайзер никогда не нажимает Enter.** Отправка мышью и сочетаниями с модификаторами не учитывается. После эмодзи Давинчика добавляется пробел, чтобы подавить предложения стикеров; не удаляй его перед отправкой.

Детектор сравнивает снимки выбранной области, а не понимает содержание анкеты. Похожие фото, видео, анимация и неверная рамка могут приводить к пропускам или ложным срабатываниям. Порог изменения доступен в настройках. Калибровка сохраняется для каждого бота; после изменения размера окна область анкеты нужно выделить заново.

## Остановка и ввод

**Ctrl+Option+S**, кнопка **«Стоп»** или **«Остановить всё»** в строке меню останавливают работу. Для глобального сочетания нужен Универсальный доступ. В голосовом режиме также распознаются «стоп» и «пауза».

Перед вставкой приложение проверяет окно и поле через Accessibility. Существующий чужой черновик не перезаписывается. После вставки проверяется содержимое, а после автоматического Enter — очистка поля; при ошибке отправка не повторяется. Прежний буфер обмена восстанавливается, если за это время пользователь не скопировал что-то новое.

Не переключай Telegram на другой чат во время работы с ботами: проверяется окно, но не имя открытого бота. Разрешённые идентификаторы клиентов перечислены в `Sources/Desktop.swift`.

## Локальные данные

| Данные | Где хранятся |
| --- | --- |
| Собственные эталоны, миниатюры и признаки | `~/Library/Application Support/ББ ДВ/reference-bank-v1.json` |
| Настройки и калибровки ботов | UserDefaults приложения `local.oshi.bbdv` |
| Сборки, окружение Python, кэши и локальные тестовые файлы | `build/` |
| Снимки при наблюдении | В памяти, без автоматического сохранения на диск |

**«Сохранить разбор»** экспортирует JSON с результатом, рамкой лица, точками и расстояниями до эталонов. Фото и миниатюры в отчёт не входят. Неоднозначный ближайший вариант остаётся в `nearest`, а `category` не заполняется. Недостающие метки перечисляются в `missing`.

Для собственной размеченной таблицы есть `Tools/SeedFaceReferences.swift`. Необязательный `assets/drawing-references.json` подхватывается при локальной сборке, но исключён из Git. Не включай его или свою базу в публикуемые исходники и сборки.

## Проверки и структура

```sh
bash scripts/test.sh
python3 scripts/check-public-files.py
```

Полный набор тестов запускается на macOS после сборки помощника. Проверяются команды и потоковая речь, правила ввода, геометрия и координаты экранов, стабильность и отмена наблюдения, сравнение эталонов и их сохранение, формат сетки и локальные модели. Автоматические тесты не отправляют сообщения в Telegram и не снимают рабочий стол.

Нативные модели могут не работать в ограниченной песочнице или без графического сеанса. Дополнительные проверки с реальными фото и размеченной таблицей пропускаются, если локальных файлов нет. Для работы программы эти тестовые фотографии не нужны.

- `Sources/` — интерфейс, ввод, речь, захват и анализ.
- `Tests/` — проверки с искусственными и необязательными локальными данными.
- `scripts/` — сборка, загрузка модели и проверка состава репозитория.
- `assets/face-mesh/` — помощник MediaPipe, версии зависимостей и лицензии.
- `Tools/` — подготовка собственной таблицы эталонов.

Сторонние компоненты распространяются со своими лицензиями в [`assets/face-mesh/licenses`](assets/face-mesh/licenses). Источник и SHA-256 модели указаны в [`NOTICE.md`](assets/face-mesh/NOTICE.md).
