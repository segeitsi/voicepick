# VoicePick

Говоришь «поставь пять» или «ну эту дизлайк», а VoicePick вводит ответ в выбранное поле. Подходит для чатов, форм и голосования.

macOS 15.2+ на Apple Silicon · Windows 10/11 x64

- **Голосовой ввод.** Числа от 1 до 10, лайк и дизлайк внутри фразы. Вместо стандартных эмодзи можно задать свой текст. Enter включается отдельно.
- **Рандомайзер.** Замечает изменение выбранной карточки и подставляет случайный ответ. Enter нажимаешь сам.
- **Анализ лица.** Открывает фото или наблюдает за фрагментом экрана, рисует карту лица и сравнивает с твоими эталонами. Всё локально.

## Запуск

**Windows.** Скачай [VoicePick.exe](https://github.com/segeitsi/voicepick/releases/latest/download/VoicePick.exe) и открой его. [Как пользоваться на Windows](docs/windows.md)

**macOS.** Нужны Command Line Tools и Python 3.12. Первая сборка скачает зависимости и модель MediaPipe.

```sh
git clone https://github.com/segeitsi/voicepick.git
cd voicepick
xcode-select --install  # если ещё не установлены
bash scripts/build.sh
open "build/VoicePick.app"
```

Дальше можно запускать через `Запустить.command`.

## Как пользоваться на Mac

Для голоса выбери **«Число 1–10»** или **«Лайк / дизлайк»**, укажи пустое поле ввода и нажми **«Запустить»**. Число или команда могут быть в любой части предложения. В новом профиле Enter выключен; для автоматической отправки включи его в настройках. Работают обычные поля, доступные через Универсальный доступ macOS.

Для рандомайзера дополнительно выдели область одной карточки в том же окне. Он оставит черновик и после твоего Enter будет ждать изменения карточки.

Для анализа лица открой фото во вкладке **«Анализ лица»** или выбери **«Выбрать область и наблюдать»** в строке меню. Главное окно при этом можно закрыть. Добавь свои эталоны хотя бы двух категорий: в репозитории база пустая. Категория показывает сходство с примерами; это экспериментальный инструмент, точность оценки привлекательности не проверена.

macOS попросит Универсальный доступ для ввода, микрофон и распознавание речи для голоса, запись экрана для наблюдения и рандомайзера. Для открытия фото доступ к экрану не нужен. Если локальное распознавание речи недоступно, используется сервис Apple.

**Остановка: Ctrl+Option+S.** В голосовом режиме работают команды «стоп» и «пауза».
