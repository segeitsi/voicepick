# VoicePick на Windows

Скачай [VoicePick.exe](https://github.com/segeitsi/voicepick/releases/latest/download/VoicePick.exe) и открой его. Нужна Windows 10 или 11 x64. Модели внутри файла. Для работы приложения интернет и Python не нужны. Первый запуск может занять несколько секунд, пока Windows распакует файл.

## Голос и рандомайзер

1. Выбери **«Голос»** или **«Рандомайзер»**, затем формат ответа.
2. Нажми **«Указать поле ввода»**. За четыре секунды переключись в нужное окно и кликни в пустое поле. Для рандомайзера так же обведи карточку в том же окне.
3. Нажми **«Запустить»** и вернись в выбранное окно. В голосовом режиме можно сказать «поставь пять» или «дизлайк». Для рандомайзера проверь черновик и нажми Enter.
4. Останови работу сочетанием **Ctrl+Alt+S**. Для голосового режима также подходят «стоп» и «пауза».

Поле должно быть доступно через Windows UI Automation. Если окно или само поле изменилось, укажи его заново. Привязка действует до закрытия окна или VoicePick. Для голоса нужен доступ к микрофону в настройках конфиденциальности Windows. Речь распознаёт [русская модель Vosk](https://alphacephei.com/vosk/models) на компьютере.

## Анализ лица

Открой фото или выдели область экрана. Во время наблюдения выбери категорию и нажми **«Добавить эталон»**, чтобы сохранить лицо из показанного кадра. Кнопки «Остановить» и «Продолжить» сохраняют положение и размер окна. Если VoicePick перекрывает выбранную область, передвинь или сверни окно. Наблюдение продолжится автоматически.

[MediaPipe](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker) строит карту лица. Категории сравниваются по локальным эталонам. Добавь свои фото или рисунки хотя бы двух категорий. База Windows хранится в `%LOCALAPPDATA%\VoicePick` и использует свой формат признаков.

Если точек лица недостаточно, VoicePick пропустит сравнение и покажет причину. Если лиц несколько, выбери нужное. Для мема или чужого фото нажми **«Пропустить кадр»**. Повтор этого кадра будет пропущен. **«Вернуть кадр»** отменяет пропуск.

## Сборка из исходников

На Windows с Python 3.12 x64 запусти из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

Готовый файл появится в `build/windows-dist/VoicePick.exe`. Сборка скачивает модели Vosk и MediaPipe и сверяет их SHA-256. По тегам `v*` GitHub Actions собирает Windows и macOS и публикует обе версии в одном релизе.
