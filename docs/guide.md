# Руководство VoicePick

VoicePick вводит короткие ответы в выбранное текстовое поле на Mac. Можно назвать число от 1 до 10, сказать «лайк» или «дизлайк» и задать для этих команд свои эмодзи или текст.

В отдельной вкладке можно открыть фото или выделить фрагмент экрана для сравнения лица с локальными эталонами.

Версия 1.4.0. Apple Silicon, macOS 15.2+, SwiftUI / AppKit.

| Режим | Что делает |
| --- | --- |
| Голос · числа | Находит число от 1 до 10 внутри фразы и вводит его в выбранное поле |
| Голос · лайк/дизлайк | Находит команду внутри фразы и вводит один из двух настроенных ответов |
| Рандомайзер | После изменения карточки подставляет случайный ответ; Enter нажимает пользователь |
| Анализ лица | Сравнивает лицо с локальными эталонами и показывает ближайшие категории и карту лица |

Для голосового ввода подходит обычное текстовое поле, которое приложение даёт читать через Универсальный доступ macOS. Это может быть поле на сайте, форма или чат. Поля паролей и диалоги входа не подходят.

Enter настраивается отдельно. В новом профиле он выключен: ответ остаётся в поле. Если включить Enter, VoicePick ожидает, что поле отправит ответ и очистится. Для форм, где Enter оставляет текст или меняет страницу, используй ввод без Enter. Анализ выделенной области экрана работает поверх любого приложения.

## Сборка и запуск

Понадобятся Mac с Apple Silicon, macOS 15.2 или новее, Command Line Tools и **Python 3.12**. Python нужен только для сборки локального детектора: в готовое приложение он упаковывается вместе с зависимостями.

```sh
git clone https://github.com/segeitsi/voicepick.git
cd voicepick
xcode-select --install  # если Command Line Tools ещё не установлены
bash scripts/build.sh
open "build/VoicePick.app"
```

Если Python 3.12 не находится командой `python3.12`, укажи его явно:

```sh
BBDV_BUILD_PYTHON=/path/to/python3.12 bash scripts/build.sh
```

Также можно запустить `Запустить.command`: при отсутствии готового приложения он сначала выполнит сборку.

Первая сборка требует интернета: зависимости устанавливаются в отдельное окружение `build/mesh-venv`, модель MediaPipe скачивается с официального сервера Google и проверяется по закреплённой SHA-256. Модель и результаты сборки не входят в Git. Во время анализа фотографии не загружаются в сеть.

## Разрешения macOS

Разрешения выдаются для конкретной локальной сборки **VoicePick** в «Системные настройки → Конфиденциальность и безопасность».

| Разрешение | Для чего нужно |
| --- | --- |
| Универсальный доступ | Ввод ответов в выбранное поле, нажатие Enter и глобальная клавиша остановки |
| Микрофон и распознавание речи | Голосовой режим |
| Запись экрана | Наблюдение за выбранным фрагментом экрана и рандомайзер |

Для анализа файла через «Открыть фото» доступ к экрану не нужен. Сам режим анализа лица ничего не вводит и не отправляет в другие приложения.

Сборка подписывается локальной ad-hoc подписью. После пересборки macOS может потребовать обновить разрешение. Сначала перезапусти приложение; если включённый тумблер не помогает, удали только запись VoicePick из соответствующего списка, добавь текущий `build/VoicePick.app` и включи доступ заново.

## Анализ области любого приложения

1. Запусти приложение. В строке меню macOS появится значок видоискателя.
2. Открой фото в браузере, «Просмотре» или другой программе.
3. Нажми значок VoicePick → **«Выбрать область и наблюдать»** и обведи фото. Наблюдение начнётся после выделения; главное окно открывать не нужно.
4. Для просмотра результата выбери **«Показать окно»**. Окна VoicePick исключены из захвата.
5. **«Остановить всё»** приостанавливает обработку; **«Продолжить наблюдение»** использует ту же область.

Источником служит изображение рабочего стола. На анализ передаётся только выбранный прямоугольник. Смена активного приложения не останавливает наблюдение. Если фрагмент перекроет другая программа, анализируется её содержимое; окна самой VoicePick исключены.

Область закреплена в координатах одного монитора и не следует за фото. После перемещения или изменения масштаба фото, смены разрешения или отключения монитора выдели её заново. Минимальный размер области составляет 80 × 80 точек.

Кнопка **«Выделить область экрана»** в разделе «Анализ лица» даёт три секунды на переключение и запускает наблюдение после выделения. Разбор обновляется после двух стабильных кадров. Закрытие главного окна оставляет приложение в строке меню. Для полного выхода используй **«Завершить VoicePick»** или Cmd+Q.

## Категории по собственным эталонам

В публичном репозитории **нет личных эталонов, фотографий, миниатюр или готовой пользовательской базы**. После сборки из чистых исходников базы фотографий и рисунков пустые.

1. Во вкладке **«Анализ лица»** нажми **«Открыть фото»**. Если лиц несколько, выбери нужное.
2. Выбери тип изображения: **«Фотографии»** или **«Рисунки»**. Базы раздельные.
3. Укажи свою категорию в **«Моя категория»** и нажми **«Добавить эталон»**. Во время наблюдения кнопка сохранит выбранное лицо из показанного кадра. Сохраняются миниатюра лица и его признаки.
4. Добавь примеры разных лиц и ракурсов. Для сравнения достаточно двух разных категорий; заполнять все семь необязательно.
5. Открой другое фото или включи наблюдение за областью экрана. Приложение покажет ближайшие примеры и результат сравнения.

Поддерживаемые метки: **sub 3 → sub 5 → LTB → MTB → HTB → stacy → true eve**. Отсутствие отдельных меток не блокирует результат: например, HTB может выбираться и без эталонов true eve.

При достаточно близком и однозначном совпадении показана выбранная категория. При слабом сходстве, единственной категории или небольшом отрыве между вариантами показана **«Ближайшая категория»** с пояснением. Расстояния до эталонов означают визуальное сходство, а не балл привлекательности или вероятность.

**Ограничения.** Это экспериментальное сравнение изображений через Apple Vision Feature Print revision 2, а не обученная и проверенная модель привлекательности. На сходство влияют причёска, освещение, ракурс, фон и стиль изображения. Для выбора категории используются расстояние не больше половины межклассового расстояния ближайшего эталона и отрыв от следующей категории. Пороги не откалиброваны на независимой выборке. Геометрические измерения в раскрываемом разделе не определяют категорию.

### Карта лица

Локальный [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker) строит сетку из 478 точек с контурами глаз, бровей, губ и овала. При пропуске лица проверяются повороты ±30°, ±60° и ±90°; точки переводятся обратно в исходное изображение. Если подробная сетка недоступна, приблизительные точки Apple Vision показаны оранжевым с соответствующей подписью.

Переключатель **«Показать карту лица»** помогает сравнить её с оригиналом. Профиль, очки, волосы, пересвет и закрытые черты могут ухудшать обнаружение и положение точек.

## Голосовой ввод

1. Открой **«Голос»** в боковой панели и выбери **«Число 1–10»** или **«Лайк / дизлайк»**.
2. Настрой переключатель **«Нажимать Enter после ввода»**. Для чатов с отправкой по Enter его можно включить. Для заполнения полей оставь выключенным.
3. Нажми **«Указать поле ввода»**. За четыре секунды открой нужное приложение и на панели выделения кликни в пустое поле. Esc отменяет выбор.
4. Нажми **«Запустить»** и вернись к выбранному окну. Ввод выполняется только в привязанном приложении на переднем плане.

Для чисел подходят фразы вроде «поставь пять, идём дальше». Через 0,35 секунды после распознавания число вводится в поле. Если за это время сказать «пять, нет, семь», выбирается последнее число. Следующую команду можно произносить без перезапуска режима.

Для реакций работают «ну эту дизлайк», «ставь лайк», «не нравится». Дизлайк имеет приоритет над лайком. По умолчанию вводятся `❤️` и `👎`; вместо них можно указать слова или короткий текст, например `да` и `нет`.

Речь распознаётся на устройстве, если локальное распознавание доступно. Иначе используется сервис распознавания Apple. Возможны ошибки распознавания. С включённым Enter ответ может быть отправлен автоматически.

Бибинта и Давинчик в Telegram остаются примерами использования: для первого подходят числа, для второго реакции. Приложение не связано с Telegram или разработчиками ботов.

## Рандомайзер

1. Выбери формат ответа и режим **«Рандомайзер»**.
2. Настрой поле ввода и выдели область одной карточки внутри того же окна, исключив кнопки, поле ввода и предыдущие карточки.
3. Для чисел задай диапазон 1–10, для реакций вероятность лайка.
4. Запусти режим и вернись к нужному окну. После стабильного кадра появится черновик.
5. Проверь его и **сам нажми обычный Enter**. Следующий черновик появится после Enter и изменения карточки.

**Рандомайзер никогда не нажимает Enter.** Отправка мышью и сочетаниями с модификаторами не учитывается. После эмодзи добавляется пробел, чтобы подавить предложения стикеров в клиентах вроде Telegram; не удаляй его перед отправкой.

Детектор сравнивает снимки выбранной области, а не понимает содержание карточки. Похожие фото, видео, анимация и неверная рамка могут приводить к пропускам или ложным срабатываниям. Порог изменения доступен в настройках. Поле и область сохраняются отдельно для чисел и реакций. После изменения размера окна выбери поле и область заново.

## Остановка и ввод

**Ctrl+Option+S**, кнопка **«Остановить»** или **«Остановить всё»** в строке меню останавливают работу. Для глобального сочетания нужен Универсальный доступ. В голосовом режиме также распознаются «стоп» и «пауза».

Перед вставкой приложение проверяет окно и поле через Accessibility. Существующий чужой черновик не перезаписывается. После вставки проверяется содержимое, а после автоматического Enter ожидается очистка поля; при ошибке нажатие не повторяется. Прежний буфер обмена восстанавливается, если за это время пользователь не скопировал что-то новое.

Привязка относится к приложению и окну. Она не различает вкладки браузера или чаты внутри одного окна. Пока ввод включён, оставляй открытым нужное поле. После изменения размера окна его нужно выбрать заново. Если приложение скрывает содержимое поля от Accessibility, VoicePick остановит ввод.

## Локальные данные

| Данные | Где хранятся |
| --- | --- |
| Собственные эталоны, миниатюры и признаки | В папке приложения внутри `~/Library/Application Support/` |
| Настройки ввода и привязки полей | UserDefaults приложения |
| Сборки, окружение Python, кэши и локальные тестовые файлы | `build/` |
| Снимки при наблюдении | В памяти, без автоматического сохранения на диск |

**«Сохранить разбор»** экспортирует JSON с результатом, рамкой лица, точками и расстояниями до эталонов. Фото и миниатюры в отчёт не входят. Неоднозначный ближайший вариант остаётся в `nearest`, а `category` не заполняется. Недостающие метки перечисляются в `missing`.

Для собственной размеченной таблицы есть `Tools/SeedFaceReferences.swift`. Необязательный `assets/drawing-references.json` подхватывается при локальной сборке, но исключён из Git. Не включай его или свою базу в публикуемые исходники и сборки.

## Проверки и структура

```sh
bash scripts/test.sh
python3 scripts/check-public-files.py
```

Полный набор тестов запускается на macOS после сборки помощника. Проверяются команды и потоковая речь, правила ввода, геометрия и координаты экранов, стабильность и отмена наблюдения, сравнение эталонов и их сохранение, формат сетки и локальные модели. Автоматические тесты не отправляют сообщения в Telegram и не снимают рабочий стол.

Нативные модели могут не работать в ограниченной песочнице или без графического сеанса. Дополнительные проверки с реальными фото и размеченной таблицей пропускаются, если локальных файлов нет. Для работы программы эти тестовые фотографии не нужны.

- `Sources/`: интерфейс, ввод, речь, захват и анализ.
- `Tests/`: проверки с искусственными и необязательными локальными данными.
- `scripts/`: сборка, загрузка модели и проверка состава репозитория.
- `assets/face-mesh/`: помощник MediaPipe, версии зависимостей и лицензии.
- `Tools/`: подготовка собственной таблицы эталонов.

Сторонние компоненты распространяются со своими лицензиями в [`assets/face-mesh/licenses`](../assets/face-mesh/licenses). Источник и SHA-256 модели указаны в [`NOTICE.md`](../assets/face-mesh/NOTICE.md).
