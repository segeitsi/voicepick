# Разработка

Проект собирается на Mac с Apple Silicon, macOS 15.2+, Command Line Tools и Python 3.12. Порядок сборки и выдачи доступов описан в [README](README.md).

Перед изменением поведения запусти соответствующие тесты, а перед публикацией исходников — проверку состава:

```sh
bash scripts/build.sh
bash scripts/test.sh
python3 scripts/check-public-files.py
```

Тесты со скриншотами, исходной таблицей и реальными фотографиями необязательны. Для новых проверок используй искусственные изображения или локальные файлы из `build/fixtures/`. Не добавляй в Git личные эталоны, миниатюры, признаки лиц, отчёты анализа, снимки экрана, настройки и ключи.

При изменении управления Telegram проверь правила черновика и отправки: рандомайзер не отправляет сообщения, голосовой режим не повторяет неудачную отправку. При изменении наблюдения проверь остановку, отмену незавершённого захвата и координаты на дополнительных мониторах.

В описании изменения укажи, какое поведение меняется и какие проверки выполнены. Для ошибки интерфейса достаточно шагов воспроизведения без личных фотографий и переписки.
